# SQLBolt Practice & Learning

In this folder you can find my solutions to the interactive exercises on SQLBolt.

## About SQLBolt
SQLBolt is a website designed to teach SQL through simple, practical lessons directly in the browser. It focuses on hands-on code execution rather than heavy theory, making it a great starting point for learning the language.

## What It Teaches
The curriculum covers the core foundations of relational databases:
*   **Data Retrieval:** Using `SELECT`, filtering rows with `WHERE`, and sorting results with `ORDER BY`.
*   **Table Relationships:** Combining data across multiple tables using `INNER`, `LEFT`, `RIGHT`, and `FULL` joins.
*   **Data Aggregation:** Summarizing data using functions like `COUNT`, `SUM`, `AVG`, and grouping results with `GROUP BY` and `HAVING`.
*   **Database Management:** Modifying data using `INSERT`, `UPDATE`, and `DELETE`, as well as creating or dropping tables.

## My Learning Goals
*   **Write clean code:** Understand how SQL code should be written and formated.
*   **Prepare to master the Dialects:** Transition from standard interactive exercises to practicing vendor-specific systems (like Microsoft SQL Server and PostgreSQL).
*   **Certification Prep:** Use these core fundamentals as a launching pad toward advanced relational database engineering and the Oracle 1Z0-071 Database SQL Certification.
